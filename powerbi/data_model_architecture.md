## 2. Table Definitions

### A. `fact_member_segments_churn` (Core Fact Table)
- **Granularity**: 1 row per loyalty member.
- **Key Metrics**:
  - `monetary_spend_eur`: Total lifetime spend across room + ancillary.
  - `recency_days`: Days elapsed since last completed checkout.
  - `frequency_stays`: Total completed stays in tracking window.
  - `churn_risk_score`: Calibrated 0–100 probability score generated by the champion XGBoost model.
  - `estimated_clv_eur`: 24-month projected Customer Lifetime Value.
- **Primary Foreign Keys**:
  - `member_id` $\rightarrow$ `dim_loyalty_members.member_id`

### B. `dim_loyalty_members` (Dimension)
- **Granularity**: 1 row per ALL loyalty member.
- **Attributes**: Tier level (`Classic`, `Silver`, `Gold`, `Platinum`, `Diamond`), enrollment cohort, country, app installation flag.

### C. `dim_properties` (Dimension)
- **Granularity**: 1 row per Accor property (representing 5,000+ hotels globally).
- **Attributes**: Brand segment (`Luxury`, `Premium`, `Midscale`, `Economy`), Brand name (`Fairmont`, `Sofitel`, `Pullman`, `Novotel`, `ibis`, etc.), Global region, City.

### D. `accor_crm_master_dataset.csv` (Flat Reporting Table Option)
- Pre-joined denormalized table designed for instant drag-and-drop analysis without needing manual relationship configuration in Power BI Desktop.
